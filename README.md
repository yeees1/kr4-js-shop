# Мерч 1С

Интерактивный адаптивный интернет-магазин на чистом JavaScript. В каталоге доступны поиск, фильтрация, сортировка, избранное и корзина.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта: `python3 -m http.server 8000`, затем откройте `http://localhost:8000/catalog.html`. Сборка и зависимости не нужны.

Автоматическая проверка сценариев: `npm test` при установленном Python и Playwright с Chromium. Для работы самого сайта они не нужны.

## Структура и JavaScript

- `index.html`, `catalog.html`, `product.html`, `products/`, `cart.html`, `order.html`, `contacts.html`, `reviews.html`, `faq.html` — страницы магазина;
- `css/style.css`, `css/responsive.css` — оформление, адаптивность и стили интерактивных состояний;
- `images/` — локальные изображения товаров и фотографии для главной страницы;
- `js/data.js` — массив из 12 товаров с уникальными числовыми `id`, едиными полями `title`, `category`, `price`, `isAvailable`, `image`, `url`, `description` и форматирование цены;
- `js/catalog.js` — генерация карточек через `createElement`, поиск, фильтрация, сортировка, избранное и пустое состояние;
- `js/cart.js` — добавление и удаление товаров, подсчёт суммы через `reduce`, сохранение корзины в `localStorage` и вывод выбранных товаров в заявке;
- `js/validation.js` — проверка заявки и вывод ошибок около полей;
- `js/main.js` — счётчик корзины в меню и кнопки добавления в корзину на страницах товара;
- `js/forms.js` — проверка и очистка формы обратной связи.

## Как работает каталог

Карточки создаются из массива товаров при открытии `catalog.html`. Поиск по названию обновляется при `input`, категория и сортировка — при `change`. Сортировка выполняется на копии списка, исходный массив не меняется. Отображаются количество результатов, состояние «товары не найдены» и кнопка сброса фильтров. Недоступный товар помечен и не добавляется в корзину. Для текста карточек и сообщений используются `textContent`, для разметки — `createElement`, `classList` и `append`; пользовательские данные и данные хранилища не вставляются через `innerHTML`. События подключены через `addEventListener`, кнопки каталога обрабатываются делегированием.

## Возможности

- Корзина на отдельной странице: кнопки «+» и «−» меняют количество каждого товара. Сумма рассчитывается через `reduce`. Счётчик в меню обновляется на всех страницах.
- Корзина и избранное сохраняются в `localStorage`; неверные или устаревшие данные корзины отбрасываются при чтении. Избранное можно включать и выключать на карточке и фильтровать одним переключателем.
- Форма заявки показывает список товаров из корзины, их количество и сумму. Пустая корзина не позволяет подготовить заявку. Ошибки выводятся у конкретных полей и общим сообщением, фокус переводится к первой ошибке, поля очищаются после проверки. Данные на сервер не передаются.
- Каталог показывает количество результатов, доступность товара, сообщение о добавлении и расширенное пустое состояние со сбросом фильтров.

## Как проверить

1. В каталоге введите «термос», смените категорию и сортировку; затем введите несуществующий запрос и сбросьте фильтры.
2. Добавьте товар в избранное, включите «Только избранное», обновите страницу — выбор сохранится.
3. Добавьте товар в корзину, откройте корзину, измените количество кнопками «+» и «−», проверьте сумму и обновите страницу.
4. Откройте заявку: проверьте список из корзины и сумму, отправьте пустую форму, проверьте ошибки e-mail и телефона, затем заполните её корректно. Появится сообщение о подготовке заявки, поля очистятся.
5. Откройте DevTools → Console на главной, в каталоге, карточке товара, корзине, заявке и контактах: критических ошибок быть не должно.
